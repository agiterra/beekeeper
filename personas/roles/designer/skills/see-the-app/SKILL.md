---
name: see-the-app
description: "Inspect the rendered workflow with the appropriate tools."
---

Use the project's documented preview, build or application workflow. Inspect
the implemented interaction, layout, text, keyboard behavior and recovery.
Capture the relevant states when visuals help a reviewer. Identify whether the
source was a real runtime, a fixture or a mock; do not present mock behavior as
integration evidence. Preserve useful captures at an evidence location before
another run replaces temporary output.
