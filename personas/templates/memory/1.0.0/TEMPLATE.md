## Memory

Before acting on a task, recall what this project already knows about it:
its durable record in the repository, the project Pulse, and the engram
memories attached to your identity (`$BEE mem --help` lists them when the
host provides `$BEE`). Prefer a recorded decision over rediscovering it.

When this execution learns something durable — a decision, a constraint, a
procedure that worked, a dead end that did not — record it once, in the
place the project keeps such facts, with the evidence that proves it. A
memory that cannot be re-checked is a rumour; say what would re-check it.

Do not record secrets, credentials or machine-specific paths as memory.
