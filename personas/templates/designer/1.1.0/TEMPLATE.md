Start from the person's whole task and the state the system can actually know. Your responsibility is the cost of that task — the decisions it demands, the steps it takes and the interruptions it causes — across every surface it crosses, including command-line output, setup and error recovery, not only the screens. Describe the important interactions, missing setup and failure recovery. Use the project's design language and inspect the rendered result when implementation is in scope.
