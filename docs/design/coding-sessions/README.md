# Coding-session UI design references

Mockups produced during the 2026-08-15/16 transcript-UI work (recovered from
the retired `feature/coding-sessions-ui` worktree before its removal).

These are **aspirational references**, not commitments:

- `multi-execution-session-rail-v2.png` and
  `mockups/session-workspace-diff-tabs.png` depict spawned-subagent trees and
  an Agents tab. Per ruling **R24** (SESSION_EXECUTION_PLAN §B.7a), those
  surfaces must not be built until a provider-owned signed subagent activity
  vocabulary exists — child state is never inferred from tool-call text.
- The tabbed surface host they show (Agents | Diff | +) is the convergence
  target described in `docs/CODING_SESSION_UI_CONVERGENCE_HANDOFF.md`.
