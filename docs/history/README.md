# docs/history — dated session reports

A session report, a lane transcript or a walkthrough record is not a finding.
Findings are numbered items in [`SESSION_STATE.md`](../SESSION_STATE.md); the
current picture is [`CURRENT_STATE.md`](../CURRENT_STATE.md). Everything else a
session wants to preserve goes here as one dated file,
`YYYY-MM-DD-<slug>.md`, and the ledger item or the map line that relies on it
links to it by path.

- **Tracked, in the repo.** A report on a Desktop or in a `review-*` directory
  beside the repo is scratch that only this machine can see; the copy that
  counts is the one here.
- **Say what was not done as plainly as what was.** A report that claims a
  gate ran cites the log path or the command's output.
- **Never rewritten after the day it describes**, except to strike a claim
  that turned out wrong, where it stands, with a pointer to what supersedes it.
- **Reports written before 2026-09-11** sit at the top of `SESSION_STATE.md`
  above its § 1, where they were written. They were left in place on purpose;
  do not move them.
